Q1. In a certain code language, 'PAPER' is written as 'QBQFS'. How is 'BOARD' written in that code?
(A) CNBSE
(B) CPBSE
(C) CPCSF
(D) CQBTE

Answer: B
Explanation:
The pattern is a simple forward shift of +1 for each letter.
P (+1) = Q
A (+1) = B
P (+1) = Q
E (+1) = F
R (+1) = S
Applying the same to 'BOARD':
B (+1) = C
O (+1) = P
A (+1) = B
R (+1) = S
D (+1) = E
Thus, 'BOARD' is coded as 'CPBSE'.

Applying the same to 'BREAD':
B (-1) = A
R (-1) = Q
E (-1) = D
A (-1) = Z

Thus, 'BREAD' is coded as 'AQDZC'.

Q6. In a certain code language, 'ACTIVE' is written as 'TCAEVI'. How is 'SUMMER' written in that code?
(A) MUSREM
(B) UMSMER
(C) REMMUS
(D) MUSMER

Answer: A
Explanation:
The word is divided into two equal halves, and each half is reversed independently.
ACTIVE → ACT | IVE
ACT reversed = TCA
IVE reversed = EVI
Combined = TCAEVI
Applying the same to 'SUMMER':
SUMMER → SUM | MER
SUM reversed = MUS
MER reversed = REM
Combined = MUSREM.

(B) VNVGIL
(C) UMUFHK
(D) VMWHJL

Refer to diagram: SVG/Q12.svg

Opposite letters:
L ↔ O, P ↔ K → OK
N ↔ M, A ↔ Z → MZ

Applying to 'METEOR':
Pairs: ME, TE, OR
Reverse pairs: EM, ET, RO
Opposite letters:
E ↔ V, M ↔ N → VN
E ↔ V, T ↔ G → VG
R ↔ I, O ↔ L → IL
Thus, 'METEOR' is coded as 'VNVGIL'.

Q14. In a certain code language, 'DIAMOND' is written as 'BJENEOP'. How is 'CRYSTAL' written in that code?
(A) ZSDTLBU
(B) YRCTMBU
(C) ZSDTMBU
(D) YSCSMAT

Answer: C
Explanation:
The 7-letter word is split into three parts: First 3 letters, the Middle letter, and the Last 3 letters.
DIAMOND → DIA | M | OND
1. First 3 reversed (AID), then shifted +1 → BJE.
2. Middle letter shifted +1 → M (+1) = N.
3. Last 3 reversed (DNO), then shifted +1 → EOP.
Combined → BJENEOP.
Applying to 'CRYSTAL':
CRYSTAL → CRY | S | TAL
1. CRY reversed (YRC), shifted +1 → ZSD.
2. S shifted +1 → T.
3. TAL reversed (LAT), shifted +1 → MBU.
Thus, 'CRYSTAL' is coded as 'ZSDTMBU'.

Reverse pairs: OH, PS, TI, LA
Shift +2:
O (+2) = Q, H (+2) = J → QJ

E (+2) = G, M (+2) = O → GO

E (+2) = G, N (+2) = P → GP
