Directions (Q1–Q15): Find the roots (values of x) for the following quadratic equations.

Q1. x² - 11x + 30 = 0
(A) 5, 6
(B) -5, -6
(C) 5, -6
(D) -5, 6

Answer: A
Explanation:
x² - 5x - 6x + 30 = 0
x(x - 5) - 6(x - 5) = 0
(x - 5)(x - 6) = 0
x = 5, 6.

----------------------------------------

Q2. x² + 7x + 12 = 0
(A) 3, 4
(B) -3, 4
(C) -3, -4
(D) 3, -4

Answer: C
Explanation:
x² + 3x + 4x + 12 = 0
x(x + 3) + 4(x + 3) = 0
(x + 3)(x + 4) = 0
x = -3, -4.

----------------------------------------

Q3. x² - 2x - 15 = 0
(A) 5, 3
(B) 5, -3
(C) -5, 3
(D) -5, -3

Answer: B
Explanation:
x² - 5x + 3x - 15 = 0
x(x - 5) + 3(x - 5) = 0
(x - 5)(x + 3) = 0
x = 5, -3.

----------------------------------------

Q4. 2x² - 7x + 6 = 0
(A) 2, 1.5
(B) -2, 1.5
(C) 2, -1.5
(D) -2, -1.5

Answer: A
Explanation:
2x² - 4x - 3x + 6 = 0
2x(x - 2) - 3(x - 2) = 0
(x - 2)(2x - 3) = 0
x = 2, 3/2 = 1.5.

----------------------------------------

Q5. 3x² + 10x + 8 = 0
(A) -2, 4/3
(B) 2, -4/3
(C) -2, -4/3
(D) 2, 4/3

Answer: C
Explanation:
3x² + 6x + 4x + 8 = 0
3x(x + 2) + 4(x + 2) = 0
(x + 2)(3x + 4) = 0
x = -2, -4/3.

(B) -4/3, 3/2

Q10. 12x² + 11x - 5 = 0
(A) 1/3, -5/4
(B) -1/3, 5/4
(C) 1/3, 5/4
(D) -1/3, -5/4

Explanation:

Q11. x² - 8√3x + 45 = 0

(B) -3√3, -5√3
(C) 3√3, -5√3
(D) -3√3, 5√3

Q12. 3x² - (6 + √5)x + 2√5 = 0
(A) 2, √5/3
(B) -2, √5/3
(C) 2, -√5/3
(D) -2, -√5/3

Answer: A
Explanation:
3x² - 6x - √5x + 2√5 = 0
3x(x - 2) - √5(x - 2) = 0
(x - 2)(3x - √5) = 0
x = 2, √5/3.
