Q1. Find the roots of the quadratic equation: x^2 - 11x + 30 = 0
(A) 5, 6
(B) -5, -6
(C) 5, -6
(D) -5, 6
Answer: A
Explanation: 
x^2 - 11x + 30 = 0
x^2 - 5x - 6x + 30 = 0
x(x - 5) - 6(x - 5) = 0
(x - 5)(x - 6) = 0
x = 5, 6.

Q2. Find the roots of the quadratic equation: y^2 + 13y + 42 = 0
(A) 6, 7
(B) -6, -7
(C) -6, 7
(D) 6, -7
Answer: B
Explanation: 
y^2 + 13y + 42 = 0
y^2 + 6y + 7y + 42 = 0
y(y + 6) + 7(y + 6) = 0
(y + 6)(y + 7) = 0
y = -6, -7.

Q3. Find the roots of the quadratic equation: p^2 - 2p - 35 = 0
(A) 7, 5
(B) -7, -5
(C) 7, -5
(D) -7, 5
Answer: C
Explanation: 
p^2 - 2p - 35 = 0
p^2 - 7p + 5p - 35 = 0
p(p - 7) + 5(p - 7) = 0
(p - 7)(p + 5) = 0
p = 7, -5.

Q5. Find the roots of the quadratic equation: 2x^2 - 9x + 10 = 0
(A) 2, 2.5
(B) -2, -2.5
(C) 2, -2.5
(D) -2, 2.5
Answer: A
Explanation: 
2x^2 - 9x + 10 = 0
2x^2 - 4x - 5x + 10 = 0
2x(x - 2) - 5(x - 2) = 0
(2x - 5)(x - 2) = 0
x = 5/2, x = 2
x = 2.5, 2.
